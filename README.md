# 🧠 Brain Tumor Classification Using Machine Learning

A deep learning project that classifies brain MRI images into **Tumor** and **No Tumor** categories using **VGG16 Transfer Learning**.
📌 About
The project preprocesses MRI images, applies data augmentation, and uses a pre-trained VGG16 model for binary classification. The model is evaluated using accuracy, precision, recall, F1-score, and a confusion matrix.
# 🛠️ Tech Stack
* Python
* TensorFlow / Keras
* VGG16
* OpenCV
* NumPy
* Scikit-learn
* Matplotlib
# 🔄 Workflow
```text
MRI Images → Preprocessing → Data Augmentation
          → VGG16 Transfer Learning
          → Training → Evaluation → Prediction
```
# 📊 Results
**Test Accuracy: 96.15%**

* Image Size: 224 × 224
* Epochs: 10
* Batch Size: 8
# ▶️ How to Run
1. Download/clone this repository.
2. Open the `.ipynb` notebook in **Jupyter Notebook or Google Colab**.
3. Make sure the dataset path is correctly set.
4. Run the cells sequentially to preprocess the data, train the model, and evaluate the results.
